# Portafolio — Leandro Mateo Scienza

Sitio personal con mi perfil, proyectos y contacto.

**Demo:** https://portafolio-peach-gamma.vercel.app/

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS y Framer Motion
- EmailJS para el formulario de contacto
- Deploy en Vercel

## Correr en local

```bash
git clone https://github.com/mateoscns/portafolio.git
cd portafolio
npm install
npm run dev
```
